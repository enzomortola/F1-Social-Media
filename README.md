# 🏎️ F1 Social App

¡Bienvenido a **F1 Social App**! La plataforma definitiva para fanáticos de la Fórmula 1 donde la comunidad tiene la palabra.

Esta es una plataforma de **código abierto (Open Source)** creada por y para fanáticos. Creemos que la mejor manera de vivir el automovilismo es compartiendo opiniones, calificando el desempeño de los protagonistas y construyendo juntos el mejor espacio para la discusión.

---

## 🌟 Características Principales

- **F1 Feed Social**: Últimas calificaciones y reviews en tiempo real de la comunidad.
- **Ránking de Pilotos y Carreras**: Calificá cada GP y a cada piloto después de la bandera a cuadros.
- **Perfil Social Personalizado**: Elegí tu escudería favorita (¡incluyendo Audi y Cadillac!), tu piloto favorito y armá tu biografía.
- **Watchlist**: Seguí a tus pilotos favoritos y no te pierdas nada.
- **Diseño Premium**: Interfaz moderna, rápida y con estética de alto nivel.

## 🛠️ Stack Tecnológico

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Base de Datos & Auth**: [Firebase](https://firebase.google.com/) (Firestore & Authentication)
- **API de F1**: [Jolpica F1 API](https://jolpi.ca/) (Ergast compatible)
- **Estilos**: Vanilla CSS con diseño responsive y animaciones dinámicas.

## 🤝 Cómo Contribuir

¡Queremos que seas parte de esto! Al ser un proyecto de código abierto, podés ayudar de muchas formas:

1. **Reportando Bugs**: Abrí un *Issue* si algo no funciona como esperabas.
2. **Sugiriendo Mejoras**: Queremos ideas nuevas (gráficos de telemetría, chat en vivo, etc.).
3. **Pull Requests**: Si sos programador, cloná el repo y mandá tus mejoras.

### Pasos para desarrollo local:

1. Clonar el repositorio: `git clone https://github.com/enzomortola/F1-Social-Media.git`
2. Instalar dependencias: `npm install`
3. Crear un archivo `.env` con tus credenciales de Firebase (mirá `src/lib/firebase.js` para los nombres de las variables).
4. Correr el proyecto: `npm run dev`
